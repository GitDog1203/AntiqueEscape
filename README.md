# AntiqueEscape
Im going to make a antique style escape room or puzzle box using as many cardputer adv features as i can!
I got one room done but it is pretty fun to play and i added gyro and sounds!
The whole idea is an escape room but on a cardputer adv so its protable for friends and stuff, i dont want to spoil but it is super good and its kinda haloween themed...

Arduino Instructions 
Arduino Setup section,

1. Install Arduino IDE
2. Go to File, then preferences, then Additional Boards Manager URLs.
3. paste this into the Additional Boards Manager URLs, https://m5stack.github.io/arduino-index/package_m5stack_index.json
4. Then go back to tools, then boards, then boards manager
5. search M5Stack and install
6. Then tools, then library manager
7. Type M5Cardputer, find M5Cardputer by M5Stack and install
8. if it asks to install other things like M5Unified accept
9. Plug cardputerAdv into the computer and uplaod the firmware
10. play!
